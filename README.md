# Авито → Telegram

Расширение Chrome для уведомлений из открытой вкладки Авито. Без платного Messenger API, сервер не нужен. Cloudflare не требуется.

## Быстрый запуск

1. Скачай `avito-tg-watch.zip` из корня ветки и распакуй.
2. Открой `chrome://extensions`, включи режим разработчика → «Загрузить распакованное расширение». Выбери папку с `manifest.json`.
3. Открой список сообщений Авито и обнови страницу.
4. В настройках расширения включи слежение. Укажи токен своего бота и Chat ID, сохрани, нажми «Тест ТГ». Можно использовать только уведомления Windows без Telegram.
5. Если счётчик не найден, нажми «Выбрать счётчик» и укажи число непрочитанных на Авито.

Полная инструкция: [INSTALL_RU.txt](avito-tg-watch/INSTALL_RU.txt).

## Ограничения

Пробная версия: проверена логика и обработка ошибок на имитации Chrome API, но не разметка реального аккаунта Авито. Обязательно проверь реальным входящим сообщением. Браузер и компьютер должны работать. Вкладка должна обновлять чаты сама; расширение не перезагружает её. Ручной счётчик замечает рост числа, но может пропускать новые сообщения в уже непрочитанном чате. Имя и превью передаются твоему боту, если распознаны на странице. Секреты хранятся локально в настройках расширения, в репозитории ключей нет.
