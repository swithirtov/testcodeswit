# Авито → Telegram · 0.4.0

Простой режим уведомлений о росте выбранного счётчика непрочитанных.
Автоответ полностью удалён. Отправка сообщений в Авито отсутствует.
Тексты переписки, имена и статусы печати не пересылаются.

## Обновление

1. Выключи старое расширение и закрой ВСЕ вкладки Авито.
2. Распакуй архив поверх папки расширения. Нажми обновление расширения в chrome://extensions.
3. Включи расширение. Открой Авито заново.
4. В расширении нажми «Выбрать число» и укажи ОБЩИЙ числовой счётчик сообщений.
   Не выбирай колокольчик уведомлений или кружок внутри отдельного чата.
5. Включи слежение и сохрани. Токен и Chat ID сохранены после обновления.
6. Первый счётчик запоминается тихо. При его росте приходит один сигнал.

Компьютер и браузер должны работать. Вкладка Авито должна обновлять число сама.
Одинаковое число не вызывает повторов. Падение числа не вызывает сигнала.
Если новое сообщение в уже непрочитанном чате не меняет счётчик, оно может быть пропущено.
Если элемент исчезает при нуле и его стабильный контейнер неизвестен, ноль не предполагается.
В таком случае возврат к прежнему числу может быть пропущен; «Проверить» покажет отсутствие счётчика.
Полная перезагрузка вкладки снова тихо фиксирует текущее число — старые уведомления не рассылаются.
Устаревшие события от прежних версий с текстами/автоответами игнорируются новым фоновым кодом.

Токен хранится локально без облачной синхронизации. Токен недоступен скрипту страницы Авито.
Ключи API Авито не нужны. Сервер и Cloudflare не нужны. На живом аккаунте проверяется пользователем.

Защита от спама: не больше одной попытки уведомления в минуту. Изменения за эту минуту могут быть объединены/пропущены.
